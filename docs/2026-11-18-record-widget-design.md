# レコードウィジェット 設計（承認済み 2026-11-18）

## 目的
動画・画面録画から取り出したお気に入り音声を、ホーム画面のレコード型ウィジェットをタップするだけで次々再生する Android アプリ。

## ゴール / 非ゴール
- ゴール: 本物のホーム画面ウィジェット（アイコンではない）。タップで再生/一時停止、次へ、曲名表示。
- ゴール: 動画（画面録画含む）から音声トラックを再エンコードなしで抽出・保存。ギャラリー選択と「共有」受け取りの両方。
- ゴール: リストの順に連続再生、末尾で先頭へループ。バックグラウンド再生＋通知操作。
- 非ゴール: 切り取り編集、マイク録音、ストリーミングサービスからの取得。
- アンチゴール: ウィジェットの常時回転アニメ（電池・制約）→ 針の上げ下げで状態表示。

## アプローチ
- 採用: Kotlin ネイティブ（AppWidget/RemoteViews + Media3 ExoPlayer/MediaSessionService + MediaExtractor/MediaMuxer）。
- 不採用: Flutter / React Native（ウィジェットは結局ネイティブで二重手間）。

## Claude の判断（未確認の既定値）
- 最低 Android 8.0 (API 26)、ターゲット API 35。
- 保存先はアプリ内部ストレージ、一覧は JSON ファイル。
- 抽出は m4a(AAC) コンテナ。AAC 以外の音声（Opus 等）は対応外としてエラー表示。
